# v8.7.8

Released: 2026-10-08

## English

### Delivery and native installation fixes

- Recognize an empty native Codex composer with adjacent model/status and shortcut/warnings rows. Accepted jobs can leave the pre-send queue without removing the status bar or changing models.
- Ordinary assistant bullets mentioning `esc to interrupt` no longer masquerade as activity. Preserve actual Working/Running, background-tool and reconnect blocking, and retire historical activity after a native Worked-for summary, including wrapped rows.
- Preserve human drafts, modal/menu blocking, conservative handling of unknown nonempty layouts, FIFO and single submission. No blind Enter retry, repeated paste or unknown-layout deadline bypass is added.
- Restore the native installation layout expected by `ccb.exe` and route `.cmd/.bat` fallbacks through the same backend entrypoint (PR #372). Payload files are replaced correctly during updates. Candidate archive validation can run without publishing; custom source refs cannot publish artifacts.
- Retain the earlier Claude pasted-envelope repair for #354, Codex status-bar compatibility repair, and the separately reviewed backend reliability changes from PR #368. The already-pasted-but-unsubmitted symptom in #356 remains open and is distinct from the reproduced pre-send queue stall.

### Publication status and upgrade

- Supersede the interrupted v8.7.7 publication. Its tag is unchanged and it is marked as an incomplete prerelease; only sidebar assets were uploaded, and npm 8.7.7 was not published. The archive installation defect was caught by a real hosted-runner smoke test and repaired before this replacement release.
- Codex CLI 0.159.2, real tmux and managed ccbd were exercised with a deterministic local Responses endpoint: two jobs completed in order, each appeared once, drafts were preserved and genuine activity still blocked sending. These tests qualify native UI/delivery, not remote model-service behavior.
- Update CCB and reopen affected projects when outstanding work can safely be interrupted so the updated daemon is loaded. No manual project, conversation or configuration migration is required.
- Desktop, npm and mobile versions are synchronized; no new mobile interface behavior is included.

### Known limitations

- PR #366 and its experimental SSH remote-workspace feature remain excluded, as requested.
- Native UI checks on Linux do not establish every macOS, WSL2/Rocky or custom-layout combination. Native archive installation, platform CI and public-package verification are recorded separately.

### 投递与原生安装修复

- Codex 原生模型/状态行与快捷键/警告行相邻显示时，能够正确识别空输入框。已接受的任务可离开发送前队列，无需删除状态栏或更换模型。
- 普通回复项目符号中的 `esc to interrupt` 不再误触发忙碌判断。保留真正的 Working/Running、后台工具及重连阻塞，用后续原生 Worked-for 提示消除历史活动证据，兼容换行显示。
- 保留人工草稿、模态/菜单阻塞、未知非空布局的保守处理、FIFO 和单次投递。不增加盲目回车、重复粘贴或未知布局超时后强行发送。
- 修复 `ccb.exe` 依赖的原生安装目录，使 `.cmd/.bat` 后备启动器也使用相同的后端入口（PR #372）。更新时正确替换载荷文件。候选归档可在不发布的情况下验证，自定义源码引用不能发布产物。

### 发布状态与升级

- 替代中断的 v8.7.7 发布。该版本的标签保持不变，已标记为未完成的预发布；只上传了 Sidebar 产物，npm 8.7.7 未发布。真实托管 runner 的安装烟测发现了归档安装缺陷，已在此替代版本发布前修复。

- 桌面、npm 和手机端版本同步更新；不包含新的手机界面行为。
