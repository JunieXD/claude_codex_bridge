# v8.7.7

Released: 2026-10-08

## English

### Codex fullscreen delivery fixes

- Recognize the empty native Codex composer when its model/status row is immediately followed by the shortcut/warnings row. Accepted jobs can now leave the pre-send queue without removing the status bar or changing models.
- Ordinary assistant bullets mentioning `esc to interrupt` no longer masquerade as native activity. Recognize actual Working/Running, background tools and reconnect states, and use later Worked-for summaries to retire historical activity, including wrapped rows.
- Preserve human drafts, modal/menu blocking, conservative handling of unknown nonempty layouts, FIFO and single submission. This release does not force delivery after an unknown-layout timeout or add repeated Enter/paste attempts.
- Retain the previously released Claude pasted-envelope repair for #354 and the earlier Codex empty-status-bar compatibility fix. The already-pasted-but-unsubmitted symptom in #356 remains open; it is distinct from the reproduced pre-send queue stall.
- Include the separately reviewed platform-specific startup, reconnect, foreground-input and build-tooling changes from PR #368. They remain confined to that backend's owned surfaces.

### Verification and upgrade

- Verified with actual Codex CLI 0.159.2, tmux and managed ccbd against a deterministic local Responses endpoint: two queued jobs completed in order, each appeared once in the native session, human drafts were preserved and actual activity still blocked sending. These tests qualify native UI and delivery behavior, not remote model-service behavior.
- Update CCB and reopen affected projects when outstanding work can safely be interrupted so the updated daemon is loaded. No manual project, conversation or configuration migration is required.
- Release, npm and mobile package versions are synchronized; there is no new mobile interface behavior.

### Publication status

Publication was stopped after a native desktop archive install failed to find its backend entrypoint. Only sidebar assets were uploaded; npm 8.7.7 was not published. Use v8.7.8 as the completed replacement. The original tag remains unchanged.

### Known limitations

- PR #366 and its experimental SSH remote-workspace feature remain excluded, as requested.
- Native UI tests on Linux do not establish every macOS, WSL2/Rocky or custom-layout combination. Platform release builds and CI verification are recorded separately from local reproduction evidence.

## 中文

### Codex 全屏界面的投递修复

- Codex 原生模型/状态行与快捷键/警告行相邻显示时，现在能够正确识别空输入框。已接受的任务可离开发送前队列，无需删除状态栏或更换模型。
- 普通回复项目符号中的 `esc to interrupt` 不再被误认成原生活动状态。识别真正的 Working/Running、后台工具及重连状态，并用后续 Worked-for 完成提示消除历史忙碌证据，兼容换行显示。
- 保留人工草稿、模态/菜单阻塞、未知非空布局的保守处理、FIFO 和单次投递。本版本不增加未知布局超时后强行发送，也不增加重复回车或粘贴。
- 保留此前发布的 #354 Claude 粘贴包装识别修复，以及 Codex 空输入状态栏兼容修复。#356 的文字已粘贴但未提交现象仍保持开放，它与本次已复现的发送前排队阻塞不同。
- 包含独立审查的 PR #368 平台专属启动、重连、前台输入及构建工具修复，改动继续限定在该后端拥有的代码范围内。

### 验证与升级

- 使用真实 Codex CLI 0.159.2、tmux 和 managed ccbd，配合本地确定性 Responses 接口验证：两条排队任务依序完成，原生会话中各出现一次，人工草稿保持完整，真正忙碌时仍阻止发送。该测试验证原生界面和投递行为，不代表远端模型服务验证。
- 更新 CCB 后，请在待处理工作可以安全中断时重新打开受影响项目，使新版 daemon 生效。无需手动迁移项目、对话或配置。
- 发布、npm 和手机端包版本同步更新；本版本没有新增手机界面行为。

原生桌面归档安装后未找到后端入口，发布流程已停止。目前只上传了 Sidebar 产物，npm 8.7.7 未发布。请改用已完成发布的 v8.7.8。原始标签保持不变。
